# 딥홀드 개인정보 처리방침


시행일: 2026-10-19

딥홀드(이하 "게임")는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하기 위해 이 방침을 둡니다.

## 1. 수집하는 항목

이메일, 실명, 전화번호, 생년월일, 결제 정보는 받지 않습니다.

| 구분 | 항목 | 수집 방법 |
| --- | --- | --- |
| 계정 | 계정 ID(무작위 생성), 닉네임, 친구 코드, 인증 토큰의 해시값 | 게임을 처음 실행하고 닉네임을 정할 때 |
| 접속 기록 | 접속 시각, 게임 버전, 운영체제 종류, IP 주소(서버 로그) | 서버 접속 시 자동 |
| 플레이 기록 | 던전 진행, 사망, 획득 아이템, 재화 사용, 소환 결과, 파티 성능 지표(핑, 지연) | 플레이 중 자동 |
| 오류 보고 | 오류 메시지, 발생 위치, 게임 버전 | 오류 발생 시 자동 |
| 친구 | 친구 목록, 친구 요청 | 이용자가 추가할 때 |

## 2. 이용 목적과 처리 근거

- 계정 식별, 기록 저장, 파티 플레이 중계
- 랭킹, 업적, 친구 기능 제공
- 부정행위(치트) 탐지와 제재
- 게임 밸런스 조정과 오류 수정
- 공지와 점검 안내

위 정보는 이용자가 요청한 게임 서비스를 제공하는 데 필요한 범위에서만 처리합니다(「개인정보 보호법」 제15조 제1항 제4호). 광고나 마케팅에는 쓰지 않습니다.

## 3. 보유 기간과 파기

| 항목 | 보유 기간 |
| --- | --- |
| 계정·기록·친구 | 계정을 삭제할 때까지 |
| 플레이 기록 | 수집 후 90일 (자동 삭제) |
| 오류 보고 | 수집 후 90일 (자동 삭제) |
| 서버 접속 로그 | 30일 (자동 삭제) |
| 제재 기록 | 제재 종료 후 90일 (자동 삭제). 영구 제재는 계정을 삭제할 때까지 |

기간이 지나면 복구할 수 없게 지웁니다.

## 4. 처리 위탁

| 받는 곳 | 맡기는 일 | 위치 |
| --- | --- | --- |
| Google LLC (Google Cloud) | 서버 운영, 데이터 저장 | 대한민국 서울 리전(asia-northeast3) |

이 밖에는 제3자에게 제공하지 않습니다. 법령에 따른 요청은 예외입니다.

## 5. 이용자의 권리와 계정 삭제

이용자는 언제든지 자기 정보의 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다.

- 게임 안 "설정 → 계정 삭제"에서 바로 지울 수 있습니다. 서버의 계정·기록·친구 정보가 즉시 지워지고, 되돌릴 수 없습니다.
- 그 밖의 요청은 아래 연락처로 보내 주세요. 10일 안에 처리합니다.

## 6. 만 14세 미만 아동

게임은 동의를 근거로 정보를 받지 않으며, 생년월일 등 나이를 알 수 있는 정보도 받지 않습니다. 만 14세 미만 아동의 정보임을 알게 되면, 법정대리인의 요청에 따라 지체 없이 지웁니다.

## 7. 안전성 확보 조치

- 서버와의 통신은 암호화(HTTPS/WSS)합니다.
- 인증 토큰은 서버에 원문을 저장하지 않고, 되돌릴 수 없는 해시값만 저장합니다.
- 관리자 기능은 인증된 운영자만 쓸 수 있습니다.
- 데이터 접근 권한을 운영자 1인으로 제한합니다.

## 8. 기기에 저장되는 정보

게임은 로그인 유지와 진행 저장을 위해 이용자 기기에 아래 정보를 저장합니다.

| 저장 위치 | 내용 |
| --- | --- |
| Windows `%APPDATA%\Deephold\` | 계정 ID·인증 토큰·닉네임, 세이브, 올리기 전 플레이 기록, 보내기 전 오류 보고, 설정 |
| Mac `~/Library/Application Support/Deephold/` | 위와 같음 |

- 게임 안에서 계정을 삭제하면 기기의 계정·토큰·세이브·플레이 기록도 함께 지워집니다. 화면·키 설정은 남습니다.
- 게임 프로그램만 지우면 이 폴더는 남을 수 있습니다. 완전히 지우려면 위 폴더를 직접 삭제하세요.
- 인증 토큰을 잃어버리면 서버에서도 복구할 수 없습니다.

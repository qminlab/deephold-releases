# 딥홀드 (Deephold)

어두운 던전을 랜턴 하나로 내려가는 2.5D 도트 액션 게임입니다.

## 다운로드

[최신 버전 받기](https://github.com/starMinK/deephold-releases/releases/latest) — `Deephold-Setup-버전.exe` 를 받아 설치하세요. 설치형은 이후 자동으로 업데이트됩니다.

## 확률 정보

[딥홀드 확률 정보 공개](docs/확률정보.md) — 드롭, 상자, 소환, 채굴 확률을 모두 공개합니다.

## 의견 남기기

버그나 개선 의견은 [Issues](https://github.com/starMinK/deephold-releases/issues) 에 남겨 주세요.
